# 🛡️ Safario – Smart Tourist Safety & Assistance System

Safario is a modern Android application designed to enhance tourist safety and travel assistance through AI-powered guidance, real-time navigation, weather updates, emergency SOS services, and intelligent location-based recommendations.

The application combines Google Maps services, AI assistance, emergency management, and modern Android development practices to create a secure and intelligent travel companion.
